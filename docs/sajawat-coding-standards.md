# SAJAWAT CODING STANDARDS

## PURPOSE

This document defines coding standards for the Sajawat platform.

All code generated by Claude, developers, contractors, and contributors must follow these standards.

Consistency is more important than personal preference.

---

# CORE PRINCIPLES

Priorities:

1. Readability
2. Maintainability
3. Scalability
4. Security
5. Performance

Code is written for humans first.

Computers second.

---

# LANGUAGE STANDARDS

Frontend:

TypeScript

Backend:

TypeScript

Never use plain JavaScript.

# TYPESCRIPT RULES

Always:

* Use strict mode
* Use explicit types where beneficial
* Use interfaces for contracts
* Use enums for business constants

Avoid:

* unknown unless justified

# EXPRESS ROUTE ORDERING

Register static routes before parameterized routes.

Static routes must be declared before dynamic (`:param`) routes
on the same path segment, otherwise the static path is captured
as a route parameter.

Correct:

router.get('/products/search', ...)

router.get('/products/:slug', ...)

Incorrect:

router.get('/products/:slug', ...)   // captures "search" as slug

router.get('/products/search', ...)  // unreachable

# COMMENTS

Tokens

Secrets

Every business-critical feature should have:

Integration Tests

# SAJAWAT MASTER PROJECT PROMPT

## PROJECT OVERVIEW

Build a production-grade luxury jewelry e-commerce platform for:

SAJAWAT JEWELLERY

This platform serves:

1. B2C Customers
2. B2B Wholesale Customers
3. Admin Staff
4. Super Admins

The platform must be scalable, maintainable, secure, and extensible.

The system must be designed for long-term growth while initially supporting approximately 200-300 SKUs and the stability-scale traffic profile.

## BUSINESS MODEL

SAJAWAT operates as:

Manufacturer
+
B2C E-Commerce Brand
+
B2B Wholesale Supplier

B2C:

Customer browses products,
adds to cart,
checks out online,
places orders.

B2B:

Customer submits inquiry form,
lead enters CRM,
admin follows up manually.

No automated wholesale checkout.

## DEVELOPMENT PRINCIPLE

Never begin implementation before:

1. Requirement Analysis
2. Architecture Review
3. Database Review
4. API Review
5. Security Review
6. Scalability Review

For any major feature:

Analyze
→ Design
→ Plan
→ Approval
→ Implement

Never skip planning.
